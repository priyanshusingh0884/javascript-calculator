# JavaScript Calculator 🧮

A responsive calculator built using HTML, CSS, and JavaScript. It supports basic arithmetic operations, percentage calculations, decimal numbers, and keyboard interactions.

## ✨ Features

- Addition, subtraction, multiplication, and division.
- Percentage calculations.
- Decimal number support.
- Clear (C) button.
- Backspace functionality.
- Equal (=) button for calculating results.
- Keyboard support for performing calculations.
- Division by zero handling.
- Responsive calculator layout.
- Interactive button hover and click effects.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners
- CSS Grid
- Flexbox
- Media Queries

## 📂 Project Structure

javascript-calculator/

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/javascript-calculator.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required.

## ⌨️ Keyboard Controls

| Key | Function |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| % | Percentage |
| Enter | Calculate result |
| Backspace | Delete last character |
| Escape | Clear calculator |
